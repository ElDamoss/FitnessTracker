2. Problèmes fréquents & solutions

❌ "Invalid nameservers" sur Cloudflare

Symptôme : Cloudflare affiche "Waiting for registrar to propagate" ou "Invalid nameservers"
Checklist :
  1. OVH Vérifie que les nameservers sont bien kanye.ns.cloudflare.com + melinda.ns.cloudflare.com (OVH → Noms de domaine → fitnesstracker.bzh → Serveurs DNS)
  2. OVH Vérifie que le statut est "Actif" (pas "En cours d'activation")
  3. OVH Vérifie qu'il n'y a aucun DS Record (OVH → DS Records → tout supprimer)
  4. OVH Désactive DNSSEC si activé
  5. CF Clique "Check nameservers now" dans Cloudflare
  6. Attends 10 min à 24h (propagation DNS)

❌ Le site ne s'affiche pas sur fitnesstracker.bzh

Symptôme : Page blanche, erreur DNS, ou "site not found"
Checklist :
  1. CF Vérifie que le domaine est "Active" dans Cloudflare (pas "Pending")
  2. CF Va dans Workers & Pages → ton projet → Custom domains → vérifie que fitnesstracker.bzh est ajouté et actif
  3. CF Va dans DNS → Records → vérifie qu'il y a un enregistrement CNAME pour fitnesstracker.bzh pointant vers fitnesstracker-4r3.pages.dev
  4. Si rien ne marche → le site est toujours accessible sur https://fitnesstracker-4r3.pages.dev

❌ Le deploy ne se fait pas après un push GitHub

Symptôme : Tu pushes sur GitHub mais Cloudflare Pages ne build pas
Checklist :
  1. CF Workers & Pages → ton projet → Deployments → vérifie s'il y a un build en erreur
  2. CF Vérifie que le repo GitHub est toujours connecté (Settings → Builds & deployments)
  3. Vérifie que le push est bien sur la branche main
  4. Si besoin → clique "Retry deployment" sur le dernier build

❌ Erreur SSL / HTTPS ne fonctionne pas

Symptôme : "Your connection is not private" ou certificat invalide
Checklist :
  1. CF Va dans SSL/TLS → mets le mode sur "Full" (pas "Flexible")
  2. CF Vérifie que le certificat est émis (SSL/TLS → Edge Certificates)
  3. Attends 15 min (le certificat se provisionne automatiquement)
  4. Si toujours KO → désactive et réactive le proxy orange ☁️ sur l'enregistrement DNS

❌ "Email rate limit exceeded" (Supabase)

Fix : Attends 10-15 min. Le plan gratuit Supabase limite à 4 emails/heure. Ou désactive la confirmation email dans Auth → Providers → Email.
