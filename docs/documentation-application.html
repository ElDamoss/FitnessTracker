📱 MuscuTrack Pro — Documentation Application

Guide complet de toutes les fonctionnalités de l'application et comment elle fonctionne.

1. Présentation

MuscuTrack Pro est une application web mobile (PWA) de suivi de musculation conçue pour un usage familial. Chaque utilisateur a son propre compte et ne voit que ses données.

📅 Programmes

Crée tes programmes personnalisés avec des jours et des exercices

🏋️ Mode entraînement

Chrono, saisie poids/reps, timer repos automatique

📊 Statistiques

Graphiques charge max et répétitions par exercice

📏 Mensurations

Suivi poids, tours de bras, poitrine, cuisses, etc.

🏆 Performances

Historique détaillé + export rapport HTML

🎨 Thèmes

Sombre, Clair, Kitty (rose), Stitch (bleu)

2. Connexion & Comptes

Créer un compte

  1. Ouvrir l'app (lien envoyé par le propriétaire)
  2. Cliquer "Créer un compte"
  3. Renseigner : prénom, email, mot de passe (6 caractères min)
  4. Le compte est actif immédiatement

Se connecter

  1. Entrer email + mot de passe
  2. L'app charge les données personnelles

Se déconnecter

Cliquer sur le bouton 🚪 dans la sidebar (ou en bas du menu mobile).

3. Pages de l'application

🏠 Tableau de bord (Accueil)

  • Volume semaine — total kg soulevés cette semaine
  • Séances mois — nombre de séances ce mois
  • Records — nombre de PRs (meilleur poids par exercice)
  • Régularité — nombre de jours consécutifs d'entraînement
  • Graphique hebdomadaire — volume par jour (7 derniers jours)
  • Programme du jour — premier jour du premier programme avec bouton "Démarrer"
  • Dernières séances — les 4 plus récentes
  • Records personnels — top 4 des charges max

📅 Programmes

Organise tes séances en programmes avec des jours.

  • Créer un programme — nom + objectif (prise de masse, sèche, force...)
  • Ajouter des jours — Push, Pull, Legs, Lundi, Jour 1... au choix
  • Dans chaque jour — ajouter des exercices avec :
    • Nombre de séries
    • Objectif de reps (ex: "8-12")
    • Temps de repos en secondes
    • Commentaire/note (ex: "Siège sur 6", "Barre W")
    • Tempo (V8) — texte libre décrivant la cadence du mouvement (ex: "3-0-1", "descente lente"), réaffiché pendant la séance
  • Réorganiser — glisser les exercices avec le handle ⠿ (animation fluide, tactile + souris)
  • Démarrer — bouton "▶ Start" → affiche d'abord le récap de ta dernière séance identique (poids/reps) puis lance

🏋️ Mode Entraînement (Workout)

Écran plein écran qui s'affiche quand tu démarres une séance.

  • Chrono global — durée totale de la séance
  • Échauffement — rappel en haut (5 min cardio + articulations)
  • Pour chaque exercice :
    • Séries avec champs kg et reps (ou secondes pour les exercices de type durée, ex: planche/gainage — V8)
    • Boutons +/- pour ajuster rapidement (±2.5 kg, ±1 rep)
    • Bouton ✓ pour valider la série
    • Tempo (V8) — affiché sous le nom de l'exercice quand il est renseigné dans le programme
  • Charges habituelles (V8) — un bouton dans l'en-tête d'un exercice ouvre une bulle listant les charges déjà utilisées pour cet exercice (recherche par nom d'exercice). Message dédié si aucun historique.
  • Échanger un exercice (V8) — remplacer un exercice en cours de séance en le choisissant dans la bibliothèque ; le nom et le muscle sont mis à jour, les séries saisies conservées, et l'échange est reflété dans le récap et l'historique.
  • Réorganiser (V8) — monter/descendre un exercice pendant la séance ; séries, valeurs saisies et état "terminé" sont conservés.
  • Commentaire par exercice (V8) — champ note repliable par exercice, consultable ensuite dans l'historique.
  • Timer de repos — se lance automatiquement après validation
    • Un seul timer à la fois (les autres s'arrêtent)
    • Bouton ⏸ pour pause
    • Bouton ✕ pour stopper
    • Vibration quand le repos est terminé
  • + Ajouter une série — bouton en bas de chaque exercice
  • Fin 🏁 — affiche le récap

📋 Récap de séance

  • Volume total soulevé
  • Durée de la séance
  • Nombre de séries complétées
  • Détail par exercice (tableau poids/reps/volume)
  • Bouton "💾 Sauvegarder" → enregistre dans l'historique
  • Bouton "Abandonner" → ne sauvegarde rien

📋 Historique

  • Liste de toutes les séances passées
  • Recherche — par nom de séance ou d'exercice
  • Filtre par mois
  • Cliquer sur une séance → détail complet (exercices, sets, poids, volumes)
  • Commentaires visibles (V8) — le commentaire de séance et les commentaires par exercice sont affichés dans le détail (message dédié si absent) ; les séries en durée sont libellées en secondes
  • Supprimer une séance

📊 Progrès (Stats)

  • Sélectionner un exercice → affiche 2 graphiques :
    • Charge max par séance (courbe)
    • Reps max (série) (V8) — le maximum de répétitions réalisées sur une seule série, et non plus la somme des reps
  • Période — 30j, 3 mois, 1 an, tout
  • Records personnels — grille avec meilleur poids par exercice + date

📏 Mensurations

  • 10 mesures par défaut — Poids, Bras G/D, Poitrine, Taille, Hanches, Cuisse G/D, Mollet, Épaules
  • "Taille" vs "Tour de taille" (V8) — le champ "Taille" (hauteur) est distinct du "Tour de taille" ; les deux valeurs sont stockées séparément (taille et tour_taille) sans s'écraser
  • Zones personnalisées — bouton "+ Ajouter une zone" pour créer les tiennes
  • Résumé — dernière valeur + delta vs mesure précédente (↑ vert / ↓ rouge)
  • Graphique d'évolution — sélectionne une mesure, vois la courbe
  • Tableau historique — toutes les entrées avec deltas
  • Saisie — date (aujourd'hui par défaut) + toutes les valeurs pré-remplies

🏆 Performances

  • Filtrer par exercice et période
  • Graphique charge max — évolution dans le temps
  • Graphique volume — évolution dans le temps
  • Tableau détaillé — date, exercice, séries, charge max, volume
  • Export rapport HTML — génère un fichier téléchargeable avec :
    • Le thème actif (sombre, clair, kitty ou stitch)
    • Résumé statistique
    • Tableau complet des performances
    • Peut être envoyé à un proche ou un coach

🏋️ Exercices (Bibliothèque)

  • Exercices pré-chargés — 42 exercices par défaut (pecs, dos, épaules, biceps, triceps, jambes, abdos, fessiers)
  • Filtrer par catégorie musculaire (chips) ou par recherche texte
  • Créer ses propres exercices (nom + muscle + description + type de mesure reps ou secondes — V8)
  • Modifier / Supprimer ses exercices perso
  • Bulle info ℹ️ — cliquer pour voir l'image de l'exercice (via API) + description détaillée

5. Installation sur téléphone

iPhone (Safari)

  1. Ouvrir le lien dans Safari
  2. Bouton partage (↑) → "Sur l'écran d'accueil"
  3. L'app apparaît comme une vraie app avec icône

Android (Chrome)

  1. Ouvrir le lien dans Chrome
  2. Menu (⋮) → "Ajouter à l'écran d'accueil"
  3. Ou accepter la bannière d'installation automatique

7. Données & Confidentialité

  • Chaque utilisateur ne voit que ses propres données (Row Level Security)
  • Les exercices par défaut sont partagés (visibles par tous)
  • Les exercices créés par un user ne sont visibles que par lui
  • Mot de passe hashé côté Supabase (jamais stocké en clair)
  • Connexion HTTPS chiffrée
  • Session non permanente (V8) — la session est stockée en sessionStorage ; à la fermeture du navigateur, une reconnexion est requise (plus de jeton conservé indéfiniment)
  • Protection anti-brute-force (V8) — les connexions sont bloquées temporairement côté serveur après plusieurs tentatives échouées pour une même adresse ; le compteur se remet à zéro après une connexion réussie ou une fois le délai écoulé

8. Limites actuelles

  • Pas de mode 100% offline (nécessite internet pour accéder aux données)
  • Pas de récupération de mot de passe (à ajouter)
  • Les zones custom de mensurations sont locales (pas synchronisées entre appareils)
  • Images d'exercices dépendent de l'API wger.de (pas toujours disponible en français)
